## 📂 Projects

---

### 📡 Ookla Broadband Equity Analysis *(Active)*
Engineered a multi-region data pipeline pulling 400K+ real-world speed test tiles
from **AWS S3** (Ookla Open Data, 2020–2025). Performed geospatial joins with U.S.
Census ACS data to analyze broadband equity across California's Central Valley,
Bay Area, and SoCal.

**Key Finding:** Rural classification is a **3x stronger predictor** of broadband
gaps than median household income.

🔗 [View Project](https://github.com/Oli-Data/Ookla-Data)

---

### 🕵️ Chicago Crime Analysis & Arrest Prediction *(Active)*
Phase 1 EDA on 192,082 crime records — trends across time, location, crime type,
and arrest rates. Phase 2 built a **4-layer PyTorch neural network** to predict
arrest likelihood, achieving **86% accuracy** with weighted sampling to handle
class imbalance.

🔗 [View Project](https://github.com/Oli-Data/Data-Science-Machine-Learning-Projects/tree/main/Chicago%20Crime%20Project)

---

### ⚡ Vercel x NVIDIA AI Hackathon — SynthSpark
Built a full-stack **Next.js** web app on **Vercel Edge Runtime** that accepts
natural language dataset descriptions and returns AI-generated schemas and
downloadable CSV samples. Integrated **NVIDIA Nemotron** via the NVIDIA API with
automatic JSON repair logic for malformed responses.

🔗 [View Project](https://github.com/Oli-Data/Vercel-Nvidia-Hackathon-day/tree/main/synthspark)
